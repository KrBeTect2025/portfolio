Python / FastAPI / WebRTC / Redis

peer

Sends a file of any size from one browser to another with a 6-digit code. A FastAPI and Redis server only introduces the two browsers; the file goes straight between them over an encrypted WebRTC channel and is written to disk as it arrives, so memory stays flat however big the file is.

50 GBsent byte for byte, receiver memory about 420 MB
  • fixOver the internet, a fast receiver got "no such code" because the code showed before the server had saved it
  • fixZipping a folder of 70,000 files overflowed the call stack
  • fixTwo receivers reading the same zip at once got a corrupt file
Works
Files up to 50 GB in Chrome, Edge and Firefox; 25 of 25 real-use scenarios, including a server restart and Redis going down mid-transfer
Not yet
Resuming after a dropped connection; Safari, phones and two different networks are not tested; 7 known issues are listed in the repo

JavaScript / Canvas

inkboard

A whiteboard where handwriting with the mouse turns into text in Excalidraw's hand-drawn font, the same size and in the same place. A bar under each word offers other readings if it guessed wrong.

The pen strokes go to Google's handwriting recognizer. It has no maths mode, so the app spots a written Σ itself by comparing up to three strokes against templates. Plain JavaScript, no build step.

Works
Writing to text, drawing, arrows, select and resize, copy and paste, undo, PNG export
Not yet
Handwriting needs internet and is sent to Google; only tested in Chrome; no automated tests
